# Say What You Know

> **10분 동안 찾아보고, 아는 만큼 말해 보세요.**

어려운 단어 하나를 받아 **10분 동안 AI 없이 검색으로 공부한 뒤**, 이해한 내용을 글이나 말로 설명하면 AI가 피드백을 제공하는 웹 학습 서비스입니다.

## 프로젝트 상태

현재 **프론트엔드·백엔드 연동 개발 단계**입니다. React 화면과 Express API, MySQL 저장소, 로컬 Ollama 채점 연동 코드를 구현했습니다. 실제 사용에는 MySQL 계정 설정, Ollama 채점 모델 설치 및 DB 초기화가 필요합니다.

## 기획 배경

AI가 답을 대신 만들어 주는 환경에서도 스스로 정보를 찾고, 내용을 정리하고, 자신의 언어로 설명하는 연습은 필요합니다.

Say What You Know는 AI를 정답을 대신 주는 도구가 아니라 **내 설명을 듣고 평가하는 청자**로 활용합니다. 먼저 스스로 학습하고 설명한 뒤, 피드백을 통해 이해한 부분과 보완할 부분을 확인하는 경험을 목표로 합니다.

## 이용 흐름

1. **단어 받기** — 분야와 난이도를 선택하면 학습할 단어 하나가 제시됩니다.
2. **10분 검색 학습** — AI를 사용하지 않겠다는 서약 후, 평소 사용하는 브라우저에서 검색으로 공부합니다.
3. **설명하기** — 처음 듣는 친구에게 알려주듯 설명합니다. 직접 입력하거나 마이크 버튼으로 말할 수 있습니다.
4. **AI 피드백** — 점수와 함께 잘한 점, 빠진 개념, 잘못 이해한 내용을 확인합니다. 빠진 개념은 정답 대신 힌트로 제공합니다.
5. **기록 확인** — 지난 도전과 피드백, 점수 변화를 확인합니다.

> AI를 사용하지 않는 학습은 사용자의 자발적인 서약을 바탕으로 합니다. 외부 브라우저에서의 AI 사용을 기술적으로 차단하거나 감시하는 방식은 아닙니다.

## 주요 기능 계획

- 분야·난이도별 학습 단어 제공
- AI 미사용 서약 및 10분 학습 타이머
- 텍스트 입력과 음성 인식을 통한 설명 제출
- 항목별 AI 채점과 힌트 중심 피드백
- 사용자별 도전 기록 및 점수 변화 조회
- 학습에 사용한 참고 링크 저장

## 기술 구성 계획

| 구분 | 기술 | 용도 |
| --- | --- | --- |
| Frontend | React, Vite, React Router | 학습 화면과 사용자 상호작용 |
| 폰트 | Pretendard | 화면 기본 서체 |
| Backend | Node.js, Express | 학습·기록 API 및 AI 채점 요청 처리 |
| Database | MySQL | 사용자, 분야·난이도, 단어장, 채점 항목, 도전 기록, 항목별 점수, 참고 링크 저장 |
| 음성 인식 | Web Speech API | 음성을 텍스트로 변환 |
| AI 채점 | Ollama (qwen2.5:3b) | 로컬에서 설명 평가 및 피드백 생성 |

AI 채점은 내 컴퓨터에서 실행되는 Ollama 모델을 사용하고(선택적으로 Gemini API로 전환 가능) 사용자 기록은 게스트 세션으로 구분합니다. 계정 로그인과 배포 환경은 추후 확장합니다. 음성 인식 지원 범위는 브라우저에 따라 달라질 수 있으며, 텍스트 입력도 함께 제공합니다.

## 데이터베이스 구조 (3NF)

| 테이블 | 저장 내용 | 관계 |
| --- | --- | --- |
| users | 세션 토큰 해시, 회원 아이디, 비밀번호 해시 | |
| fields | 분야 이름 | |
| difficulties | 난이도 이름 | |
| words | 단어, 영어 표기, 채점용 참고 개념 | fields, difficulties 참조 |
| criteria | 채점 항목 키, 이름, 배점, 평가 내용 | |
| challenges | 진행 상태, 제출한 설명, AI 글 피드백, 시작·채점·완료 시각 | users, words 참조 |
| challenge_scores | 도전별 항목 점수 (기본키: 도전 + 항목) | challenges, criteria 참조 |
| reference_links | 도전에 첨부한 참고 링크 | challenges 참조 |

총점은 따로 저장하지 않고 challenge_scores의 점수를 더해 계산합니다. 분야·난이도 목록과 채점 항목은 화면과 AI 채점이 모두 DB에서 읽어 사용합니다.

## 실행 안내

### 백엔드 (server)

Node.js **22.12 이상**, MySQL **8.0 이상**, [Ollama](https://ollama.com)가 필요합니다. 채점 모델은 `ollama pull qwen2.5:3b`로 내려받습니다. API는 기본적으로 로컬 컴퓨터에서만 수신합니다.

1. `server/.env.example`을 `server/.env`로 복사합니다. 이미 로컬 설정 파일이 있다면 덮어쓰지 않습니다.
2. `DB_USER`, `DB_PASSWORD`, `DB_NAME`을 로컬에서 설정하고 `AI_PROVIDER=ollama`가 들어 있는지 확인합니다. `.env`는 Git에 포함되지 않습니다.
3. 아래 명령으로 패키지를 설치하고 테이블·초기 단어장 24개를 준비합니다. 초기화 계정에는 데이터베이스 및 테이블 생성 권한이 필요합니다.

```powershell
cd server
npm ci
npm run db:init
npm run dev
```

별도 터미널에서 프론트엔드를 실행합니다.

```powershell
cd client
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. Vite가 `/api` 요청을 `http://127.0.0.1:3001`로 전달합니다.
`http://127.0.0.1:3001/api/health`에서 MySQL 연결 여부와 AI 채점 설정 여부를 확인할 수 있습니다. 채점 전에 Ollama가 실행 중이어야 합니다.

### 환경 변수

| 변수 | 기본값 / 설명 |
| --- | --- |
| `HOST`, `PORT` | `127.0.0.1`, `3001` |
| `DB_HOST`, `DB_PORT` | `127.0.0.1`, `3306` |
| `DB_USER`, `DB_PASSWORD` | MySQL 계정과 비밀번호 |
| `DB_NAME` | `saywhatyouknow` |
| `AI_PROVIDER` | `ollama`이면 로컬 Ollama로 채점. 비워 두면 Gemini API 사용 |
| `OLLAMA_MODEL` | 기본값 `qwen2.5:3b`. `ollama list`에 있는 다른 모델로 변경 가능 |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | 선택. Gemini로 채점할 때만 사용 (만 18세 이상 발급 가능) |
| `APP_ORIGIN` | `http://localhost:5173`. 운영 환경에서는 실제 서비스 출처 설정 |
| `NODE_ENV` | 운영 시 `production`; HTTPS 보안 쿠키 사용 |

### API

| 메서드 | 경로 | 기능 |
| --- | --- | --- |
| GET | `/api/health` | DB 연결 및 AI 설정 상태 |
| GET | `/api/words?field=과학&difficulty=보통` | 분야·난이도별 단어 조회. 채점용 참고 개념은 응답에 포함하지 않음 |
| POST | `/api/challenges` | `{ wordId }`로 도전 생성 |
| POST | `/api/challenges/:id/start` | `{ pledged: true }`로 서약 및 학습 시작 |
| POST | `/api/challenges/:id/submit` | `{ explanation, links: [url] }`로 설명 제출·AI 채점·기록 저장 |
| GET | `/api/challenges/:id` | 본인의 도전과 피드백 조회 |
| GET | `/api/history` | 본인의 최근 완료 기록 최대 100개 및 통계 |

설명은 20~10,000자, 참고 링크는 HTTP(S) 주소 최대 20개입니다. 학습 타이머는 10분이며, 학습을 일찍 마쳤을 때 제출하는 것도 허용합니다.
참고 링크는 출처 기록용으로 저장하고 서버에서 해당 URL을 열거나 AI에 전달하지 않습니다.
채점 요청이 중복되면 동시에 처리하지 않으며, 완료된 도전의 재전송에는 기존 결과를 반환합니다. 실패하면 다시 제출할 수 있고, 서버 중단으로 남은 채점 잠금은 5분 뒤 재제출 시 회수합니다.

### 기록과 AI 처리

현재는 **게스트 방식**입니다. 서버는 임의의 세션 토큰을 HttpOnly 쿠키로 전달하고 토큰 해시를 사용자 식별에 사용합니다. 쿠키를 삭제하거나 다른 브라우저를 사용하면 이전 기록에 접근할 수 없습니다. 회원가입·계정 로그인·기록 복구는 미구현입니다.

설명과 참고 링크, 점수, 피드백은 MySQL에 저장됩니다. 작성 중 설명과 학습 상태는 현재 탭의 sessionStorage에도 보관합니다. 제출한 설명 텍스트와 단어·분야·채점용 참고 개념은 로컬 Ollama(`127.0.0.1:11434`)로만 전달되어 외부로 나가지 않으며 음성 원본은 이 백엔드로 업로드하지 않습니다. Web Speech API의 음성 처리는 브라우저 제공자의 정책을 따릅니다.

채점은 Ollama의 구조화 출력(JSON Schema `format`)을 사용하며 서버에서도 점수 범위를 검증합니다. 로컬 모델은 PC 사양에 따라 응답에 시간이 걸릴 수 있어 최대 180초까지 기다립니다. Ollama·DB 연결이 없으면 설정 오류를 표시하고 예시 점수로 대체하지 않습니다. AI 평가의 정확성과 힌트가 정답을 과도하게 노출하지 않는지는 실제 학습 설명으로 추가 검증이 필요합니다. 초기 단어장은 개발용으로, 운영 전 출처 보강과 내용 검토가 필요합니다.

### 검증

```powershell
cd server
npm test
cd ../client
npm run build
```

서버 테스트는 테스트 전용 메모리 저장소와 가짜 채점기를 주입해 API 흐름, 사용자별 접근 제어, 입력 검증, 중복 제출, 채점 실패 후 재시도를 검증합니다. 실제 MySQL·Ollama 통합 검증을 대신하지 않습니다. 실제 연동 검증은 환경 변수를 설정하고 DB 초기화 후 도전을 완료하여 확인합니다.

운영 배포 시 프론트엔드와 `/api`를 같은 HTTPS 출처로 제공하고, 제한된 권한의 DB 계정과 프록시 환경에 맞는 요청 제한 설정을 적용해야 합니다. 현재는 로컬 개발용이며 배포하지 않았습니다.
