# Say What You Know

> **10분 동안 찾아보고, 아는 만큼 말해 보세요.**

어려운 단어 하나를 받아 **10분 동안 AI 없이 검색으로 공부한 뒤**, 이해한 내용을 글이나 말로 설명하면 AI가 피드백을 제공하는 웹 학습 서비스입니다.

## 프로젝트 상태

현재 **기획 및 초기 설정 단계**입니다. 아래 기능과 기술 구성은 개발 예정 사항이며, 실행 가능한 애플리케이션은 아직 포함되어 있지 않습니다.

## 기획 배경

AI가 답을 대신 만들어 주는 환경에서도 스스로 정보를 찾고, 내용을 정리하고, 자신의 언어로 설명하는 연습은 필요합니다.

Say What You Know는 AI를 정답을 대신 주는 도구가 아니라 **내 설명을 듣고 평가하는 청자**로 활용합니다. 먼저 스스로 학습하고 설명한 뒤, 피드백을 통해 이해한 부분과 보완할 부분을 확인하는 경험을 목표로 합니다.

## 이용 흐름

1. **단어 받기** — 분야와 난이도를 선택하면 학습할 단어 하나가 제시됩니다.
2. **10분 검색 학습** — AI를 사용하지 않겠다는 서약 후, 평소 사용하는 브라우저에서 검색으로 공부합니다.
3. **설명하기** — 처음 듣는 친구에게 알려주듯 설명합니다. 직접 입력하거나 마이크 버튼으로 말할 수 있습니다.
4. **AI 피드백** — 점수와 함께 잘한 점, 빠진 개념, 잘못 이해한 내용을 확인합니다. 빠진 개념은 정답 대신 힌트로 제공합니다.
5. **기록 확인** — 지난 도전과 피드백, 점수 변화를 확인합니다.

> AI를 사용하지 않는 학습은 사용자의 자발적인 서약을 바탕으로 합니다. 외부 브라우저에서의 AI 사용을 기술적으로 차단하거나 감시하는 방식은 아닙니다.

## 주요 기능 계획

- 분야·난이도별 학습 단어 제공
- AI 미사용 서약 및 10분 학습 타이머
- 텍스트 입력과 음성 인식을 통한 설명 제출
- 항목별 AI 채점과 힌트 중심 피드백
- 사용자별 도전 기록 및 점수 변화 조회
- 학습에 사용한 참고 링크 저장

## 채점 기준

| 항목 | 배점 | 평가 내용 |
| --- | ---: | --- |
| 정확성 | 40점 | 설명한 내용이 사실과 개념에 부합하는가 |
| 핵심 개념 포함 | 30점 | 단어를 이해하는 데 필요한 핵심 개념이 포함되어 있는가 |
| 쉬운 설명 | 20점 | 처음 듣는 사람도 이해할 수 있는 표현과 예시를 사용하는가 |
| 논리적 구성 | 10점 | 설명이 일관된 흐름으로 연결되는가 |
| **합계** | **100점** | |

## 기술 구성 계획

| 구분 | 기술 | 용도 |
| --- | --- | --- |
| Frontend | HTML, CSS, JavaScript | 학습 화면과 사용자 상호작용 |
| Backend | Node.js, Express | 학습·기록 API 및 AI 채점 요청 처리 |
| Database | MySQL | 사용자, 단어장, 도전 기록, 참고 링크 저장 |
| 음성 인식 | Web Speech API | 음성을 텍스트로 변환 |
| AI 채점 | LLM API | 설명 평가 및 피드백 생성 |

LLM 제공자와 모델, 인증 방식, 배포 환경은 추후 결정합니다. 음성 인식 지원 범위는 브라우저에 따라 달라질 수 있으며, 텍스트 입력도 함께 제공합니다.
